## 5.3 鉴权与签名

原生侧有独立的加密库 `lib/arm64-v8a/libhaidii_crypto.so`（9,304 字节），
以及 `libhaidiihrc.so`（1.65 MB，HRC 资源/握手）。

从 Java 层可见的鉴权要素：

1. **设备指纹**：`HaidiiAppEnvApi.getAtypeId()`（产品号，如 `17001`）、
   `getAtypeName()`（产品名）、`isShangdi()`（渠道形态）、
   `HaidiiAppSignatureApi.getSignatureSha256()`（APK 签名 SHA-256）。
2. **设备授权**：`AppRequestApi.deviceAuth` → `DeviceAuthRequestBean`，
   `AppRequestApi.devices` → `DevicesRequestBean.HaidiiDeviceInfo`。
3. **公共请求基类**：`AppBaseRequestBean` 携带设备号、版本、渠道等公共字段，
   随每次请求上传。
4. **加密库**：`libhaidii_crypto.so` 提供签名/加密原语。

> 由于词典释义查询完全本地，**实现「查询词的全部意思」不需要任何鉴权**，
> 因此本逆向项目不涉及签名还原。

## 5.4 与本地词库的联动：离线词库下发

`AppRequestResult.AppOfflineLexiconRequestData` 表明服务端可以下发

## 5.5 结论

| 问题 | 结论 |
|---|---|
| 查一个词的全部释义需要联网吗？ | **不需要**。全部释义、发音、例句都在 APK 内的本地词库中。 |
| 需要鉴权吗？ | **不需要**。 |
| 哪些功能必须联网？ | 词库增量更新、在线翻译、AI 语法/写作、TTS 语音合成、笔迹识别、账号与内购。 |
| 解密词库需要什么？ | `atypeId`（=17001）与固定基址 `948873246`，两者相加得到 key。 |
