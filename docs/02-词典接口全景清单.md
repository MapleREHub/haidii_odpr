# 02 · 词典接口全景清单

> 本文档汇总逆向过程中定位到的**全部**与词典相关的接口，分为五层：
> 应用门面层 → 业务编排层 → DAO 层 → JNI 层 → 原生 C 层。

---

## 2.0 一句话结论

词典释义的查询**完全在本地完成**。词库随 APK 打包在 `assets/ciku/*.adgz`，
由原生库 `libhdmdblib.so` 解密解包、`libhdlex.so` 建索引并检索；
网络侧只承担词库更新下载、发音(TTS/音频)、翻译、AI 语法/写作、笔画取词等辅助功能。

### 关键：`atypeId` 与解密密钥的关系

```kotlin
// com.haidii.framework.repo.lexicon.dao.a（DaoAppLocalDict）
public a(String str, String str2, int i, int i2) {
    this.f1514a = str;      // 源文件路径（.adgz）
    this.b = str2;          // 目标文件路径（.dgz）
    this.c = i + 948873246; // ← 密钥 = atypeId + 948873246
    this.d = i2;            // 句柄
}
```

本应用 `atypeId = 17001`（`HaidiiAppEnvApi.getAtypeId()`），
故 **密钥 key = 17001 + 948873246 = 948890247**。

### 3.3 `com.haidii.ciku.BaseDaoLocalDict` —— **真正的接口定义（13 个 native 方法）**

```java
public abstract class BaseDaoLocalDict {
    public native int      loadADict(int shangdi, int handle, String path, int key);   // 载入 .dgz
    public native void     releaseADict(int handle);                                 // 释放
    public native int      convertADict(int shangdi, String src, String dst, int key);// .adgz → .dgz
    public native byte[]   searchByKey(int handle, String key);                      // 按词查（主查询）
    public native int      searchByKeyForUwid(int handle, String key);                // 按词查 → uwid
    public native byte[]   searchByUwid(int handle, int uwid);                       // 按 uwid 取记录
    public native byte[][] searchByUwidBatch(int handle, int[] uwids);               // 批量取
    public native String   searchByUwidField(int handle, int uwid, String field);     // 取指定字段
    public native byte[]   searchByUwidForKey(int handle, int uwid);                 // 由 uwid 反查 key
    public native byte[]   searchForKeys(int handle, int uwid);                     // 同类词
    public native String   searchForSameKeys(int handle, String key);                // 同 key 族
    public native String   querySplit(int handle, String text);                     // 中文分词
    public native byte[]   clickCnMatch(int handle, String a, String b);            // 点击取词匹配
}
```

> **这 13 个方法就是「词典相关的接口」的原子集合。**
> 后续的 `LexiconSearch` / `HybridSearchEngine` / UI 层都只是它们的编排。

## 2.5 第 5 层：原生 C 层（`libhdmdblib.so` 导出符号）

IDA 9.3 无头分析 `libhdmdblib.so` 得到的完整导出表（词典相关部分）：

### 词库装载 / 解密
| 符号 | 说明 |
|---|---|
| `loadAdgz` / `freeAdgz` | 打开/关闭 `.adgz`（解析 13 字节头） |
| `decompressAdgzTyped` | `.adgz` → `.dgz`（**解密 + inflate**） |
| `hdgz_decrypt` | ADGZ 密钥流生成与 XOR 解密 |
| `hdgz_load_dict` / `hdgz_free_dict` | 载入/释放 `.dgz` 词库（mmap + 建索引） |

### 检索
| 符号 | 说明 |
|---|---|
| `hdgz_search` | 主检索（按 key） |
| `hdgz_search_by_uwid` | 按 uwid 检索 |
| `hdgz_get_uwid_by_key` | key → uwid |
| `hdgz_get_uwid_by_keyindex` | keyindex → uwid |
| `hdgz_get_key_by_keyindex` | keyindex → key |
| `hdgz_get_key_by_uwid` | uwid → key |
| `hdgz_get_keys` | 取 key 列表 |
| `hdgz_search_binaryitem_details` | 二进制条目详情 |
| `hdgz_prefix_match` | 前缀匹配 |
| `hdgz_search_for_same_keys` | 同 key 族 |
| `hdgz_click_cn_match` | 点击取词匹配 |
| `hdgz_query_split` | 中文分词 |
| `hdgz_extract_json_field` / `hdlex::extractJsonField` | 从 JSON 记录中提取字段 |

### 课文 / 阅读（Reading）
`hdgz_reading_get_chapter`、`_get_chapter_ju`、`_get_chapter_duan`、`_get_chapter_shiwen`、
`_get_chapter_segitems`、`_get_chapter_highlightitems`、`_get_chapter_audio_highlightitems`、
`_get_chapter_slice`、`_get_boundaries`、`_get_description`、`_get_guwen`、
`_get_highlightstructure`、`_ext_parser`、`_search_by_segid`、`_trim_body_pages`

### 词库注册表
`hdgz_registry_load` / `_acquire` / `_release_ref` / `_close`

### 第三方依赖
`cJSON_*`（JSON 解析）、`inflate` / `inflateInit2_`（zlib）、`mmap` / `madvise`（内存映射）、
`open`/`read`/`fstat`、`/dev/urandom`（随机数，仅用于生成 `.dgz` 时的掩码）
